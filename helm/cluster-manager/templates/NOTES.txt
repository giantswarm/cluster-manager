{{- if and .Values.oauth.enabled .Values.github.enabled }}

muster connects through the GitHub App's per-person login: the bearer is the person's App user token (commit mode's pull request), and the platform identity provider's ID token rides next to it in X-Muster-Id-Token (forwardIdentity).
{{- else if .Values.oauth.enabled }}

Every call must carry a bearer token of the platform identity provider; muster forwards the session's token (forwardToken).
{{- else }}

Try it:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "cluster-manager.fullname" . }} 8080:{{ .Values.service.port }}
  curl -s localhost:8080{{ .Values.mcp.path }} -H 'Content-Type: application/json' -H 'Accept: application/json, text/event-stream' \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"list_clusters","arguments":{}}}'
{{- end }}
